Credits & sources

ARC Quest is an independent local player for the original ARC-AGI-3 public environments. It is not affiliated with or endorsed by ARC Prize.

Original games and scoring

All 25 public games, ARCEngine 0.9.3, and the ARC-AGI Toolkit 0.9.9 scorecard code are by the ARC Prize Foundation and distributed under the MIT license. Game sources and the original engine and scoring modules are bundled without changes in engine.zip. The adapter and interface are separate.

Practice scores

Game scores use the original SDK’s RHAE calculation and real human baselines. The benchmark score averages all 25 game scores in the current run; unplayed games count as zero. This is practice, including repeated attempts, not an official benchmark or leaderboard submission. The test-only solver is never included in the game.
